# Luma Ecommerce Product Page

A Next.js + TypeScript + Tailwind CSS ecommerce product-page demo.

## Run in VS Code

1. Open this folder in VS Code.
2. Open **Terminal → New Terminal**.
3. Run:

```bash
npm install
npm run dev
```

4. Open the localhost address shown in the terminal (usually `http://localhost:3000`). If port 3000 is already in use, Next.js will use another port such as 3001.

## Images

The previous version used local placeholder SVGs, which caused the product areas to look empty/broken compared with the reference. This version uses real sneaker photographs hosted by Unsplash URLs, so no missing local image files are required.
